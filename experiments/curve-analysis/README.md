# Reproducible CartPole curve ensemble

Run `node experiments/curve-analysis/analyze.mjs` from the repository root. This reruns the exact 128 seeds in `seeds.json`, using the preserved `rl.snapshot.mjs` implementation. The snapshot is byte-for-byte identical to the app's `dist/rl.js` at experiment time; the original path and SHA-256 are recorded in `manifest.json`. `analyze.mjs` is dependency-free Node ESM and uses three worker threads.

The original ensemble took 53.131 seconds on this Mac with Node v26.0.0. All 128 jobs completed. Every run used the unchanged PPO defaults (32-unit actor/critic, 1,024-step rollouts, 8 epochs, batch 64, actor and critic learning rate 0.001, discount 0.99, GAE lambda 0.95, clip 0.2, entropy coefficient 0.005), 80 updates, and 81,920 environment steps. Seeds were sampled without replacement from 32-bit unsigned integers using `crypto.randomBytes`. Only the seed changed across runs. The environment is the app's CartPole implementation, including its 500-step episode cap.

`results.json` contains the complete experiment: `runs` has all 128 histories, all completed episode scores, and independent sampled-policy evaluations. Each history point records update, total environment steps, exact most-recent-20-episodes training score, total episode count, the relevant 20 episode IDs/scores, and newly completed episode IDs/scores. The primary curve agrees with the app's displayed training score. It is a rolling mean across recent episodes and recent policies, not a pure evaluation of the checkpoint immediately after that update. `evaluation` separately records 20 new sampled-policy episodes at updates 0, 10, 20, 40, and 80; those draws never consume the trainer's RNG.

`summary.json` contains the same overall statistics and clusters without the complete `runs` or optimization restart logs. Running the script also generates `runs.jsonl` with individual complete run records in worker completion order; this duplicate bulk file is ignored by Git. `manifest.json` lists fixed settings. Progress and the final result are printed to standard output.

The clustering uses Euclidean distance between each pair of 80-point training curves after dividing scores by 500. PAM k-medoids uses 32 deterministic seeded starts and repeated best-improving full swaps, retaining the smallest sum of distances to representatives. Each representative is an actual run, not an average synthetic curve. Three groups are a requested descriptive compression; this procedure does not discover or establish that nature has exactly three learning types. Group IDs are ordered by descending within-group median training score at update 20. Shares count runs assigned to those fitted groups. Their 95% Wilson intervals condition on the fitted boundaries and exclude uncertainty in learning those boundaries from this same sample.

Overall and within-group `p10`/`p90` arrays show pointwise run-to-run variability. They are not confidence intervals for a mean, and they are not a simultaneous envelope containing 80% of entire trajectories. Quantiles use linear interpolation of sorted observations.

A dip is a strict decrease between adjacent update score samples. Consecutive decreases form one contiguous dip; a contiguous dip of at least 25 score points is marked substantial. Maximum drawdown measures the largest peak-to-later-trough difference, possibly spanning separate dips. Threshold statistics use the first training rolling mean at least 475. `kmMedianSteps` is the first time at least half the group reached that threshold, retaining right-censored failures at the 81,920-step horizon. `medianStepsAmongReached` is the usual interpolated median among those who reached it. In this experiment all 128 runs reached the threshold, and every final training rolling mean was exactly 500. This is convergence observed within this sample and horizon, not a universal guarantee.

Verification: seed 189998643 was rerun independently with the preserved source; all 80 score samples and every training episode score matched bit for bit. Syntax checks passed. Evaluation draws use SHA-256-derived seed values from the run seed and update and are separate from training.

The ten 50-point histogram bins had counts `[0,0,1,10,34,38,20,19,5,1]`. At the final horizon, all training scores were 500, a ceiling point mass. No normal distribution was assumed or fitted.
