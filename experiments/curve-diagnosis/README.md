# Diagnosis scripts and recorded summaries

The selected dip is from training seed `162066966`, under the unchanged PPO snapshot in `../curve-analysis/rl.snapshot.mjs`.

Run commands from the repository root:

```sh
node experiments/curve-diagnosis/evaluation/diagnose.mjs
node experiments/curve-diagnosis/evaluation/confirm.mjs
node experiments/curve-diagnosis/evaluation/center-holdout.mjs
node experiments/curve-diagnosis/interventions/run.mjs
node experiments/curve-diagnosis/audit/epoch-trace.mjs
node experiments/curve-diagnosis/ablations.mjs
node experiments/curve-diagnosis/control-field.mjs
```

`evaluation/README.md` explains frozen-checkpoint tests, physical failure causes, chart lag, and independent holdout validation. `interventions/README.md` explains same-batch learning-rate tests. `audit/epoch-report.md` records the original optimizer epoch trace; `audit/review.md` describes implementation checks and attribution limits.

`ablation-summary.json` records frozen-policy logit and cart-input interventions. `control-field.json` records analytic local policy derivatives and counterfactual force grids. `centering-contrast.json` contains the main-cohort bias interaction; the independent holdout contrast is in `evaluation/holdout-validation.json`.

The recorded summaries are committed so plots can be rendered directly. Bulk raw episode arrays and instrumented source copies are intentionally regenerated by the scripts and ignored by Git. These diagnostics explain this selected run and do not establish a universally optimal controller intervention or training setting.
